# African Chronicle

A single-page news website for African news — breaking-news ticker, story sections, search, light/dark theme, and share buttons (WhatsApp, Facebook).

## View it live (GitHub Pages)

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute your site will be at `https://<your-username>.github.io/<repo-name>/`.

## Run locally

Just open `index.html` in any web browser — no build step or install needed.
